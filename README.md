The script in this repository is used to generate a site map showing locations where macroinvertebrates and periphyton have been collected as part of CDPHE Biohab sampling. 
Note: only reference and stressed sample sites are plotted; additional samples from sites that are not reference or stressed exist and should be incorporated into this map or a different map in the future.
The intention behind this map is to identify geographic area or biotypes that may need additional periphyton samples to inform development of data sets for a periphyton/diatom biological index. 
This map is very complicated and is trying to convey a lot of information; thus, it's not very accessible/friendly at first glance, and some institutional knowledge is needed to understand it! 
Data will not be stored in this repository, and plotting theme code is also not included. Those items may be added if repository is made private.
